# Figure guide

Current manuscript: [soil, porewater, and sediment](../analysis/SOIL_POREWATER_SEDIMENT_MANUSCRIPT.md),
updated October 10, 2026. All figure outputs remain in this directory, with
individual panels retained beside combinations. Filenames are stable because
scripts and reports refer to them directly.

## Current comparative figures

Generated by `analysis/microbes/19_soil_porewater_sediment.R` after cohort
preparation. These figures use 15 soils, 34 sediments, and 27 porewater samples;
same-site comparisons use the verified 18-site overlap.

| Review first | Purpose |
| --- | --- |
| [Sampling map](2016_soil_porewater_sediment_sampling_map.pdf) | Habitat coverage, 13 mapped soils, and the 33 sediment microbial-molecular paired sites |
| [Habitat context](2016_soil_porewater_sediment_habitat_context.pdf) | Refit Hellinger PCA and q = 1 diversity |
| [Soil sharing](2016_soil_porewater_sediment_soil_sharing.pdf) | Read and ASV overlap with the regional soil inventory across drainage area |
| [Same-site comparisons](2016_soil_porewater_sediment_same_site_comparison.pdf) | Sediment-porewater dissimilarity and read sharing at the identical 18 sites |

Individual panels use the same `2016_soil_porewater_sediment_` prefix. Full
captions, test designs, inventory sensitivity, and limitations are in the
[cohort report](../analysis/microbes/README_SOIL_POREWATER_SEDIMENT.md).

## Within-sediment figures

These datasets are unaffected by the suspect water-library exclusions. Use
all 34 microbial samples and 44 molecular profiles when each is described
separately, and the identical 33 sites when directly comparing datasets.

| Figure family | Interpretation and source |
| --- | --- |
| `2016_sediment_ms_*` | Reformatted sediment composition, conditions, dispersion, and UniFrac; [panel guide](../analysis/figures/README_SEDIMENT_FIGURES.md) |
| [Matched dispersion](2016_matched_sediment_dispersion_comparison.pdf) | Identical sites and balanced selections; [methods](../analysis/fticr/README_MATCHED_SEDIMENT_DISPERSION.md) |
| `2016_sediment_characteristics_*` | Sediment condition models and sample coverage; [methods](../analysis/fticr/README_SEDIMENT_CHARACTERISTICS.md) |
| `2016_sediment_stable_group_*`, `2016_sediment_bipartite_*` | Exploratory selected association group and null diagnostics; [methods](../analysis/fticr/README_BIPARTITE_NETWORKS.md) |
| `2016_fticr_*`, `2016_dom_*`, `2016_integrated_chemistry_*` | Molecular incidence, detection diagnostics, and measured chemistry; [FT-ICR guide](../analysis/fticr/README.md) |

Equal-feature molecular thinning remains a sensitivity analysis. Complete
profiles and detection diagnostics should accompany interpretation. The core-2
branch hypothesis remains unaudited. Different microbial and molecular
significance levels are not a test that the responses differ.

## Historical or supporting sets

Original cross-habitat microbial diversity/PCA, planktonic/hyporheic dispersion,
water-community chemistry, merged-water detection inventories, and catchment
iCAMP figures predate the reviewed cohort. They include excluded libraries
or planktonic communities and are not current comparative manuscript evidence.
Their files remain available for provenance; a historical sediment-only panel
can still retain the correct sediment set.

`archive/soil_first_pass/` contains explicitly archived soil examples and
distance/branch plots, with its own [archive note](archive/soil_first_pass/README.md).
Pilot figures are explicitly excluded from Git in the root `.gitignore`.
Legacy `sed_microbial_pcoa.png` and `sed_molecular_pcoa.png` belong to the
older mothur/R Markdown workflow and remain in place with that analysis.

No figure was moved or deleted during the October 10 repository tidy-up.
