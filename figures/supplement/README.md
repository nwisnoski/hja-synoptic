# Supporting figures

This directory contains individual panels, alternative ordinations, complete-
profile and full-site comparisons, detection diagnostics, condition models,
sampling maps, and other supporting figures. These are supporting candidates;
placement here does not mean every file is proposed for a published supplement.

Current comparative figures use prefix `2016_soil_porewater_sediment_`.
First-detection richness and read panels are retained individually here.
Sediment integration uses `2016_sediment_ms_`, `2016_fticr_`,
`2016_sediment_stable_group_`, and `2016_sediment_bipartite_` prefixes.

Historical soil panels remain under `archive/soil_first_pass/`. Legacy mothur
plots retain their filenames and historical interpretation. Explicitly ignored
exploratory and pilot plots remain local and are not newly tracked.

See [the figure guide](../README.md), [main manuscript figures](../manuscript/README.md),
and [caption and method notes](../../analysis/MANUSCRIPT_FIGURES.md).
